# Publicação

1. Copie todos os arquivos e a pasta `.github` para a raiz de `thiagocavfer/thiagocavfer`.
2. Commit e push para `main`.
3. No GitHub, abra **Actions > Update profile stats > Run workflow** para preencher as estatísticas reais.
4. Se o workflow não conseguir enviar os arquivos, em **Settings > Actions > General > Workflow permissions**, habilite permissões de leitura e escrita.
5. Personalize os repositórios fixados usando **Customize your pins** na página do seu perfil.

**Importante:** o SVG do Andrew é uma imagem, então dentro dele não se pode selecionar/copiar os dados como texto comum do README. Esta adaptação apresenta as informações novamente em Markdown abaixo da imagem, onde são totalmente copiáveis. Os números de commits e linhas de código foram omitidos porque seu cálculo exige varreduras extensas e pode gerar dados enganosos. As métricas de repositórios/seguidores/estrelas são preenchidas por consulta real ao GitHub na Action, não por números inventados.
